# DivulgaPro

Primeira versão estrutural do aplicativo web DivulgaPro AI.

O aplicativo é uma interface SaaS em português do Brasil para comerciantes criarem campanhas simuladas a partir de produtos e fotos. Inclui tela inicial com barra de criação inteligente, sugestões rápidas, modelos prontos, painel com sidebar responsiva, cadastro de produtos, identidade da marca, fluxo de nova campanha, resultado em abas, calculadora de ofertas, calendário, banco de ideias, toasts, estados vazios, estados de erro e estrutura `campaignGeneratorService` preparada para integração futura com IA real sem expor chaves no navegador.

## Como visualizar

Abra `index.html` no navegador.
